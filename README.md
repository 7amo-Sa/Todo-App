# Todo App 📝

A modern and clean Todo application built with **Flutter** and **Dart**, designed to help users organize and manage their daily tasks through a simple and intuitive interface.

## 📱 About The Project

Todo App is a Flutter application created to provide a simple and practical way to manage daily tasks.

The project focuses on clean UI, organized code structure, reusable components, and a smooth user experience.

The application is currently under development and can be extended with additional task management and productivity features.

---

## ✨ Features

- 📝 Create and manage tasks
- ✅ Mark tasks as completed
- 🔄 Update task information
- 🗑️ Delete tasks
- 📋 Display and organize tasks
- 🎨 Clean and modern user interface
- 📱 Responsive Flutter UI
- 🚀 Custom application icon
- 🧩 Organized project structure
- ⚡ Smooth user experience

🚀 Getting Started
Prerequisites
Make sure you have the following installed:
Flutter SDK
Dart SDK
Android Studio or Visual Studio Code
Android SDK
Git
You can verify your Flutter installation using:
flutter doctor
📥 Installation
Clone the repository:
git clone https://github.com/7amo-Sa/Todo-App.git
Open the project directory:
cd Todo-App
Install Flutter dependencies:
flutter pub get
Run the application:
flutter run
📱 Build APK
To generate a release APK:
flutter build apk --release
The generated APK will be available at:
build/app/outputs/flutter-apk/app-release.apk
For architecture-specific APK files:
flutter build apk --split-per-abi
